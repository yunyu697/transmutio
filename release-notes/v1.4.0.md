# Transmutio 1.4.0

次版本（`1.4.0`）：把 Renomio 那一轮验证过的界面经验搬到 Transmutio，只沿用做法，
数值一律取 Transmutio 自己的规范（正文 12 / 控件高档 28 / 行高 32 / compact / 侧栏 240）。
本轮不动转码链路、不动预设格式、不动设置页与首次引导。

## 令牌与字号

- 组件里的裸色值清零（18 处 `rgba()` / 字面色 → `color-mix()` 语义槽），圆角与控件高
  全部走角色令牌。
- 控件高从 10 个散值收到一档主值 28：24 只留给行内小按钮，36 留给空状态块，40 给条栏
  与抽屉头；行高 32 不变。
- 字号从 6 档（11/12/13/14/16/20，另有一处内联 11.5）收到 4 档：11 说明、12 正文、
  14 卡片与面板标题、20 页标题。层级由「字号 + 颜色」两个维度拉开，不再靠 1px 差。
- 页标题 16 → 20，正文 : 页标题由 1.23 提到 1.67（规范要求 ≥1.6）。
- `.card` 的圆角从 `role-panel`（14）改回 `role-card`（10），比容器小一档。

## 层级压缩

- 标题到首行列从 4 层 180px 收到 2 层 75px；首屏结构横线 11 条 → 1 条；首屏墨迹密度
  50.5% → 59.7%。
- 页头去掉副标题，只留标题 + 添加文件；拖拽区只在 0 文件时渲染；`.fl-head` 与表头合并
  成一层。
- 短列表按内容收口：4 个文件时表格不再撑到窗口底部，状态栏只在有选中项时出现。

## 说明文字

- 25 个面板的常驻说明块 94 → 1，字数 5474 → 35，提示位 0 → 12。
- 删掉 63 处 `.note`：能力边界类保留一句，其余进 `title` 或直接删除（处置清单见批次 C）。
- `Group` / `Field` 新增可选 `hint`，渲染为行内 `title`，不占版面。

## 列表

- 对齐口径统一：序号左、名称/类型/时长左、大小右对齐并启用 `tabular-nums`、状态左、
  操作右；表头跟随数据侧。序号不再单独做「只在一列右对齐」的特例（本来就是左）。
- 图标视框从 `0 0 24 24` 收到 `2 2 20 20`，图形占视框 83% → 100%；渲染尺寸从 7 档收到
  3 档（按钮与导航 16、紧凑 14、表头与行内 12），空状态插画 22 → 20。

## 快捷键

- 新增 `Space`（切换当前行勾选）与 `/`（聚焦左栏搜索）。
- 键位提示不再常驻：行尾 `Space` / `F2` / `Del` 与搜索框 `/` 默认 `opacity:0`，只在悬停
  或用键盘聚焦列表（`:focus-visible`）时浮出；键帽左侧 28% 渐隐到行底色，覆盖数值时不出
  硬切边。

## 缩放

- 缩放改为「折叠优先、不重排」：删掉 700px 处的两栏纵向翻转与 38vh 封顶，任何档位都保持
  左右两栏。
- 折叠顺序：参数面板收窄（402 / 360 / 320）→ 收「类型」列 → 收「时长 / 尺寸」列 → 工具条
  按钮隐藏标签（保留 `title`）。只隐藏内容，按钮高、内边距、字号一律不变；分段控件改
  `nowrap`，靠省略号而不是折行。
- 窗口下限由无实测支撑的 1080×680 改为逐档实测的 **900×600**（860 时文件表出现 19px
  横向裁切，故不再往下放）。

## 拖拽排序

- 本轮只做回归确认：松手即同步落位（`pointerup → finish() → list.move()`），没有静默
  阈值或延后刷新，与上一版一致，无需改动。

## 验证

- `npm run build`：TypeScript 类型检查 + Vite 构建通过。
- `npm run test:list`：24/24 PASS；`npm run verify:ui`：39 PASS / 0 FAIL。
- `npm run verify:theme`：72 PASS / 0 FAIL（4 套配色 × 2 种亮度）；`npm run check:bundle`：
  36/36 PASS；`npm run version:test`：18/18 PASS。
- 逐档视觉实测：1440×900 / 1200×800 / 1080×680 / 1000×700 / 960×680 / 900×640 / 900×600，
  七档下文件表横向溢出均为 0，控件高保持 20/24/28 不变。

**未做真实窗口人工走查**：本轮为无头浏览器实测（1440×900 DPR 1 + mock 数据），所以拖影
手感、滚动惯性、真实 WebView 下的字体度量与最小窗口拖拽体验仍需在真机窗口确认。

## 安装与校验

- 安装包**未签名**：无 Authenticode、无 Apple Developer ID / 公证；更新包 `.sig` 是 minisign
  签名，与代码签名不是一回事。
- FFmpeg 不随包分发，运行时按设置里的路径或自带构建解析。
- 每个 Release 附 `SHA256SUMS`（安装包与 `.sig` 的 SHA-256），下载后可自行核对。
