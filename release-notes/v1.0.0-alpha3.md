# Transmutio 1.0.0-alpha3

预发布（prerelease），不建议日常使用。

## 本阶段做了什么

- **首次启动可选下载 FFmpeg**：内置清单（编译进二进制，运行时不可替换），登记官方发布 +
  3 个加速镜像；失败按顺序回退并实时显示当前来源。
- **强制校验**：每个来源的文件落盘前都比对内置 SHA-256；镜像给的文件一律不采信，
  不匹配即删除并换下一个来源，绝不落盘。
- **许可变体对应**：LGPL 包只下载 LGPL 构建（BtbN，不含 x264/x265），GPL 包只下载 GPL 构建；
  下载前拒绝跨变体包，落位后再读一次构建配置复核，不匹配即回滚。
- **断点续传与重试**：`Range` 续传（服务器不支持时自动从头），每来源最多 3 次重试；
  下载前检查磁盘空间，不足直接拒绝并给出需要/可用数字；失败原因逐项可读（断网/超时/HTTP/哈希）。
- **落位与手动方式并存**：下载完成落到 `<应用数据目录>/tools/ffmpeg-<版本>/`，仍保留手动选择
  本地可执行文件的方式；不把二进制提交进仓库，安装包也不包含它们。
- **可选下载 Poppler**：「PDF 转图片」面板缺 `pdftoppm` 时可直接下载 Poppler（同一套清单与校验，
  落位到 `tools/poppler-<版本>/Library/bin/` 并写入设置）。
- macOS / Linux 没有可固定官方 SHA-256 的发布包：清单只给手动/包管理器方案与可读原因，
  **不伪造可下载项**。

## 实测（本机 Windows x64，真实公网）

- FFmpeg LGPL `N-128433-gdb8537d8cc`：175,646,783 字节，55s，SHA-256 匹配，解压 + 落位 + 构建配置校验通过。
- Poppler `26.09.0-0`：43,709,956 字节，48s，SHA-256 匹配，落位后 `pdftoppm` 可检测。
- 镜像 ghproxy.net：107s 下载 Poppler，SHA-256 与官方一致（镜像内容同样被内置校验和约束）。
- 离线断言：`cargo test download::` 10/10、`tools-check` 11/11（含校验拒绝、空间不足、续传分支、
  变体不匹配、无包平台只返回手动原因）。

## 已知限制

- **安装包未签名**（无 Authenticode / Apple 公证），Windows SmartScreen 可能提示未知发布者；
  未做签名就不声称已解决。
- macOS / Linux 的 FFmpeg/Poppler **没有自动下载**，只能手动或包管理器安装（原因见上）。
- 第三方镜像的存活与速度不受本项目控制；失败会自动回退官方源。
- 真实窗口内点击下载/取消的 UI 操作本轮未做（需可见窗口的前台 GUI 验证）；下载核心与进度事件
  已由离线/真实下载检查覆盖。
- Linux 只产出 deb + AppImage（RPM 版本号不接受 `-alphaN`，不产 rpm）。
- 本阶段没有做 macOS / Linux 真机窗口与转码实跑（下一阶段单独做）。
