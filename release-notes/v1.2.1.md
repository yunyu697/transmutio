# Transmutio 1.2.1

补丁版本（`1.2.1`）。本次只修一件事：界面字号与行高整体偏小。无功能增删，
无数据格式变化，设置与预设可直接沿用。

## 根因（先量后改）

用真实安装包（真实 WebView2，非 headless 模拟）读回：

- `GetDpiForWindow = 192`（200%）、`devicePixelRatio = 2`、窗口 `outerWidth/innerWidth = 1.0000`
  → DPI 感知正常（PerMonitorV2 生效），**不是** DPI 位图拉伸问题；
- 字体栈实测落到 `Segoe UI`（`Inter` 未安装），中文回退微软雅黑 → **不是**字体族问题；
- `body` 的 `font-size` 为 **12.5px**，行高为 `normal`（≈1.2）；辅助文本
  `.side-label` **9px**、`.statusbar` / `.hint` **10.5px** → **设计基准偏小**。

对照 Windows 系统 UI 基准 Segoe UI 9pt = 12px @100%：辅助文本低 12.5%，
`.side-label` 低 25%。

## 改动

- 字号整体上调一档（8→11、9→11、9.5→11、10→11.5、10.5→12、11→12.5、11.5→13、
  12/12.5→13、13→14、14→15、15→16、16→17、18→19、20→21）；
- `body` 行高改为 `1.5`，表单控件 `line-height: inherit`；
- 音频等分段控件允许换行（13px 下 6 个格式按钮会挤出容器，实测 348px > 329px）；
- 首页速览卡的「上次参数摘要」取消单行省略，改为可换行。

改后读数（真实安装包，100% / 125% / 150% 三档一致）：

| 位置 | 改前 | 改后 |
| --- | --- | --- |
| 正文 `body` | 12.5px / normal | **13px / 19.5px（1.5）** |
| 分区导航 | 12.5px | 13px / 19.5px |
| 文件列表 | 11.5px（表头 10.5px） | 13px（表头 12px） |
| 状态栏 | 10.5px | 12px / 18px |
| 表单标签 `.side-label` | 9px | 11px / 16.5px |
| 说明文字 | 10.5px / 15.75px | 12px / 18px |
| 面板标题 | 13px | 14px |

## 验证

- 真实安装包测量（WebView2 调试通道）：100% / 125% / 150% 三档
  `truncated=2 / clipped=0 / horizontalOverflow=false`；2 条截断均为速览卡副标题的
  单行省略（改前同样是 2 条，非本次回归）。
- 浏览器断言（headless Edge + mock 后端，**不是真机验证**）：`panel-persist` 22/22 PASS。
- 版本文件：`version:check` 通过（`1.2.1`）。

## 已知限制（不美化）

- **安装包未签名**：无 Authenticode、无 Apple Developer ID / 公证；更新包 `.sig` 是 minisign，
  与应用签名不是一回事。
- macOS / Linux 由 CI 构建，本版仍无实机运行验证。
- `<select>` 的计算后 `line-height` 仍为 `normal`（Chromium 对表单控件的 UA 行为），
  13px 文本在 30px 控件内无裁剪。
- FFmpeg 不随包分发；本次未改动转码链路与预设格式。

## 附件

- Windows / macOS / Linux 安装包（LGPL / GPL 两个变体）+ 每个包对应的 `.sig`
- `latest.json`（LGPL）/ `latest-gpl.json`（GPL）
- `SHA256SUMS`：安装包与 `.sig` 的 SHA-256
