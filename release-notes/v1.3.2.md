# Transmutio 1.3.2

补丁版本（`1.3.2`），只改侧栏折叠/展开按钮的位置与对齐：从左上角挪到侧栏底部靠右，
并和底部图标行、搜索框对齐。没有接口、设置项或流程变化。

## 折叠/展开按钮：底部靠右

- 位置从左上角改到左栏底部靠右，距右边、底边各 **10px**。
- 10px 不是随手取的数：侧栏内边距 8px + 底部图标行内边距 2px = 10px，所以按钮右沿
  落在 **225px**，与搜索框右沿、底部图标行右沿完全重合；底沿 **796px** 与设置那几个
  图标同一条基线，不再出现「只贴某一边、像浮在外面」的观感。
- 仍然是**同一个按钮节点**：两态都只有 1 个 `.collapse` 元素，只换箭头方向与
  `aria-label`（收起侧栏 / 展开侧栏）、`aria-expanded`，不新增第二个按钮。

### 折叠态的处理

折叠后侧栏只剩 64px 图标列，按钮如果继续贴右边会偏离列轴 6px，看起来像贴边悬浮。
因此折叠态改为**列居中**：与上面三个 `.railbtn` 同一轴线（中心 x=32，偏差 0）。

同时底部图标列让出按钮占用的高度（底部 10px + 按钮 32px = 42px），并向内多留 8px，
最低的图标与按钮之间实际净距 **8px**，不再互相遮挡。
