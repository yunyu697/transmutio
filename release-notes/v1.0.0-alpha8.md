# Transmutio 1.0.0-alpha8

**alpha 版本，不建议日常使用。** 构建未做 Authenticode / macOS 公证；首次运行会触发系统提示。

## 本阶段做了什么

- **设置图标**：原「设置」图标只是「圆 + 8 条射线」，与主题切换的太阳图标几乎同形；
  现替换为标准齿轮线性图标，线宽与全组一致（1.6px，`currentColor`，16/18px 内联 SVG）。
- **标题栏跟随主题**：新增 `set_window_chrome` 命令，切换主题时同时设置窗口
  `theme`（light/dark）与 `background_color`；Windows 11 额外用 DWM
  `DWMWA_CAPTION_COLOR` / `DWMWA_BORDER_COLOR` 把标题栏涂成顶栏渐变起点色（`--ff-bg2`），
  去掉标题栏与内容区之间的色差线。Windows 10 不支持 caption color 时自动回退为
  light/dark 标题栏，不做伪标题栏。
- **更新包签名链路**（alpha7 起生效）：每个安装包都有 `.sig`，Release 同时提供
  `latest.json` / `latest-gpl.json` 与含签名的 `SHA256SUMS`；安装前强制校验
  大小 + SHA-256 + minisign 签名，没有跳过校验的开关。

## 平台能力

| 平台 | 能力 |
| --- | --- |
| Windows（NSIS `-setup.exe`） | 检查 + 安装（安装器静默运行，应用退出后完成安装并重启） |
| macOS（`.dmg`） | 检查 + 下载（打开 DMG 手动拖入「应用程序」） |
| Linux AppImage | 检查 + 安装（替换当前 AppImage 后重启） |
| Linux deb | 检查 + 下载（安装交给包管理器） |

## 已知限制

- 未做 Authenticode / macOS 公证，系统仍会提示「未知发布者」。
- GitHub API 未认证时限流 60 次/小时；镜像可能同样限流。
- 仅升版本，不提供降级/回滚按钮。

## 附件

- 三平台安装包（LGPL / GPL 两个变体）+ 每个包对应的 `.sig`
- `latest.json`（LGPL）/ `latest-gpl.json`（GPL）
- `SHA256SUMS`：安装包与 `.sig` 的 SHA-256
