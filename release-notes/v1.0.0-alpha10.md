# Transmutio 1.0.0-alpha10

**alpha 版本，不建议日常使用。** 构建未做 Authenticode / macOS 公证；首次运行会触发系统提示。

## 本版目的

验证 alpha9 引入的 Windows 静默安装自动重启链路：alpha9 的更新器已改为 `/S /R`，
本版作为「下一个 alpha」用于真机走通「检查更新 → 下载 → 安装 → 自动重启 → 新版本号」。

功能内容与 1.0.0-alpha9 相同：

- Windows NSIS 静默安装传 `/S /R`，安装完成后由安装器以当前用户身份重启新版本；
  MSI 路径不自动重启，界面如实提示「安装完成后请手动打开」。
- 码控方式：默认 / 恒定质量 / 目标码率 / 保持原始；旧别名 `same` / `original` / `copy` / `keep` /
  「与源相同」读回后映射到「保持原始」。
- 恒定质量五档（近乎无损 / 高质量（推荐）/ 标准 / 省空间 / 极小体积），CRF 数字收进「高级」。
- 音频码率档位化（标准 / 高 / 更高 / 极高 + 默认 + 保持原始），kbps 数字收进「高级」。

## 平台能力

| 平台 | 能力 |
| --- | --- |
| Windows（NSIS `-setup.exe`） | 检查 + 安装（安装器静默运行，应用退出后完成安装并自动重启） |
| Windows（MSI） | 检查 + 安装（静默安装，不自动重启，安装完成后请手动打开） |
| macOS（`.dmg`） | 检查 + 下载（打开 DMG 手动拖入「应用程序」） |
| Linux AppImage | 检查 + 安装（替换当前 AppImage 后重启） |
| Linux deb | 检查 + 下载（安装交给包管理器） |

## 附件

- 三平台安装包（LGPL / GPL 两个变体）+ 每个包对应的 `.sig`
- `latest.json`（LGPL）/ `latest-gpl.json`（GPL）
- `SHA256SUMS`：安装包与 `.sig` 的 SHA-256
