# Transmutio 1.3.1

补丁版本（`1.3.1`），只做品牌图标换新：应用图标统一换成 crystal-indigo 浅色底版本，
界面内的品牌图标按明暗切换。

1.3.0（工作台式界面 + 首帧修复）已经发布，本次没有接口、设置项或流程变化，
所以走补丁版本而不是次版本；如果你希望把图标算作一项可见变化，也可以按
`1.4.0` 处理，但按语义化版本规则它不构成新功能。

## 应用图标：一律浅色底版

新图标来自 crystal-indigo 系列，深色底版只用于界面内；**所有系统层图标统一使用浅色底版**：

- 多尺寸 ICO：`16 / 24 / 32 / 48 / 64 / 128 / 256`
- Tauri icons：`icon.png`（1024）、`128x128.png`、`128x128@2x.png`、`64x64.png`、`32x32.png`
- Windows Store：`Square30/44/71/89/107/142/150/284/310Logo.png`、`StoreLogo.png`
- macOS：`icon.icns`（16 / 32 / 64 / 128 / 256 / 512 / 1024）
- 安装器（MSI / NSIS）、窗口图标、任务栏、开始菜单、文件关联图标都读取同一份 `.ico / .png`

### 16 / 24 / 32px 做了光学版本

原图直接缩到 16px 时三张卡片会糊成一团，白色字形完全消失。新增
`src/assets/brand-light-small.svg` 作为小尺寸光学版本：去掉投影、玻璃高光与细描边，
卡片加宽并拉开，卡片间加白色分隔，中心波形加粗，只保留「三张彩色卡片 + 白色字形」
这一层信息。

实际观感（预览图 `samples/icon-preview/`，8× 最近邻放大；不入库）：

- **32px**：三张卡片边界清晰，中心蓝色卡片上的白色波形可辨，能看出「三色叠卡」；
- **24px**：三张卡片仍分得开，中心波形退化为两块白色像素，整体识别正常；
- **16px**：三色块仍可区分（青 / 蓝 / 紫），字形退化为白色亮点，作为任务栏小图够用；
- 48px 起改用原图，保留渐变与玻璃质感。

## 界面内图标：只跟明暗

- 新增 `BrandMark`：浅色主题显示 `brand-light.svg`，深色主题显示 `brand-dark.svg`。
- 切换依据是 `data-theme`（首帧内联脚本就已写好的解析后明暗），**与 `data-palette` 无关**：
  4 套配色 × 2 种明暗仍然是 2 张图，不会膨胀成 8 套。
- 两张 SVG 常驻 DOM 并预加载，切主题时靠 CSS `display` 切换，不出现空图或二次请求。
- 侧栏品牌位从「128px PNG 取景裁切」改为直接渲染 SVG，不再需要 34.03px 渲染盒。

## 旧标识排查

- 删除旧源图 `src-tauri/app-icon.svg`（无引用）。
- 移除 `SideNav` 里对 `src-tauri/icons/128x128.png` 的取景盒引用，改为品牌 SVG。
- 启动页（引导页）、设置/关于、空态、错误页均无品牌位图：它们只使用 `Icon.tsx` 的线性图标集，
  没有旧 logo 残留。
- 安装向导图、窗口图标、任务栏/开始菜单图标都来自重新生成的图标集，已是新标识。

## 首帧

`index.html` 的内联首帧脚本只写 `data-theme` / `data-palette` 与底色，不引用图标或品牌位图，
本次无需修改；浅色首帧仍是 `#E9F1FB`、深色 `#0A0E14`，不会出现旧标识或跳色。
