# Transmutio 1.2.2

补丁版本（`1.2.2`）。本次只改界面：启动闪屏、切换动效、设置页长度、侧栏折叠按钮
与侧栏密度，另定了一套间距标尺并据此修掉功能区与任务列表之间缺失的留白。
无功能增删，无数据格式变化，设置与预设可直接沿用。

## 根因（先量后改）

启动闪烁用真实安装包逐帧采样（`PrintWindow(hwnd, hdc, PW_RENDERFULLCONTENT)`，
约 100ms 一帧）定位，1.2.1 的启动序列是：

| 时刻 | 画面 |
| --- | --- |
| 0–213ms | 无窗口 |
| 213–1100ms | 只有窗口底色 `#0A0E14` |
| ~1105ms | **整屏渲染引导页**（"第一次使用：先准备 GPL 构建的 FFmpeg…"） |
| ~1207ms | 被主界面替换 |

不是窗口显示过早，也不是字体/布局跳变：`needsSetup` 在首帧由 `tools === null`
推出 `!ffmpegReady`，于是先渲染引导页；`resolve_tools` 异步返回后才切主界面，
所以每次启动都会整屏闪一下引导页。

## 改动

- **启动**：能力探测出结果前只铺底色（`bootDone` 门闩），不再渲染引导页；
  `index.html` 内联首帧底色并按已存设置预置 `data-theme`，避免深/浅跳变。
- **动效**：视图切换 180ms 淡入 + 上移 5px，子分区/明细展开 120ms，任务中心与
  设置抽屉 180ms 右滑，遮罩淡入，侧栏宽度改过渡。`prefers-reduced-motion: reduce`
  下动画与过渡统一压到 0.001ms，不强行动画。
- **设置**：硬件能力检测默认收起为一行摘要（视频/音频/解码可用数与探测时间），
  明细按需展开，带 `aria-expanded`。
- **侧栏折叠按钮**：折叠态与展开态共用同一个按钮、同一坐标，只换图标方向与
  `aria-label`；折叠态底部旧的"展开侧栏"按钮删除。
- **侧栏密度**：新增"最近使用"/"转换分区"分组标题，子项加左侧竖线缩进，
  行高与点击热区统一放大。
- **间距标尺**：`--sp-1 4 / --sp-2 8 / --sp-3 12 / --sp-4 16 / --sp-5 20 /
  --sp-block 24`，分别用于行内、控件之间、面板内部、容器内边距、区块之间、
  页面底部留白，主要区域按标尺重新排布。

改后实测：

| 位置 | 改前 | 改后 |
| --- | --- | --- |
| 启动帧序列 | `#0A0E14` → **引导页** → 主界面 | `#0A0E14` → 主界面（无引导页帧） |
| 设置抽屉滚动高度 | 5248px（6.3 屏） | **2423px（2.9 屏）** |
| 硬件能力分组高度 | 3012px | **173px**（摘要 94.5px） |
| 折叠按钮（展开态 / 折叠态） | 22×22 @ (203,11) / 38×34 @ (12.5,810) | **32×32 @ (8,8) / 32×32 @ (8,8)** |
| 分区行 / 子项高 | 29.5–31.5px / 24.8px | **34px / 32px** |
| 底部图标按钮 | 30×26（折叠态 38×34） | **32×32（折叠态 40×36）** |
| 功能区 → 任务列表净空 | **0px** | **20px** |

## 验证

- 真实构建产物（WebView2 调试通道）几何实测：两态折叠按钮坐标完全一致，
  `side-scroll` 无溢出滚动（scrollHeight = clientHeight = 644）。
- 浏览器断言（headless Edge + mock 后端，**不是真机转码验证**）：
  `verify:ui` 39/39 PASS，`panel-persist` 22/22 PASS。
- 版本文件：`version:check` 通过（`1.2.2`）。

## 已知限制（不美化）

- 启动仍有一帧 WebView2 初始空文档画布 `#121212`（约 1 帧）。已验证窗口
  `backgroundColor`、WebView2 controller `DefaultBackgroundColor`（Tauri
  `set_background_color`）与 Chromium `--default-background-color` 都改不动这一帧，
  属浏览器进程的空白文档底色，未采用"延时显示窗口"之类的掩盖手段。
- **安装包未签名**：无 Authenticode、无 Apple Developer ID / 公证；更新包 `.sig` 是 minisign，
  与应用签名不是一回事。
- macOS / Linux 由 CI 构建，本版仍无实机运行验证。
- FFmpeg 不随包分发；本次未改动转码链路与预设格式。
