# Transmutio 1.0.0-alpha7

**alpha 版本，不建议日常使用。** 构建未做 Authenticode / macOS 公证；首次运行会触发系统提示。

## 本阶段做了什么

- **更新包签名正式启用**：生成 minisign 密钥对（私钥只存仓库外与 CI secret，绝不入库），
  公钥写入 `src-tauri/updater.pub`。
- **发布流水线**：tag 触发后为每个安装包生成 `.sig`，缺失即失败；同时产出
  `latest.json` / `latest-gpl.json`（含签名、大小、下载地址），`SHA256SUMS` 现在也包含 `.sig`。
- **更新器兼容修复**：正确解析 Tauri signer 的 base64 包裹签名与 base64 包裹公钥，
  并保留「公钥缺失 → 拒绝安装」的 fail-closed 行为，没有跳过校验的开关。
- **AV1 视频编码**（既有能力的确认与实测）：MP4 / MKV / WebM 均可选 AV1，软件走
  SVT-AV1 → AOMedia AV1，硬件候选 NVENC / AMF / QSV / VAAPI 按试编结果灰显。
- 平台能力如实标注：Windows「检查 + 安装」；macOS「检查 + 下载（打开 DMG）」；
  Linux AppImage「检查 + 安装（替换后重启）」；Linux deb「检查 + 下载」。

## 签名与校验口径

- 安装前必须通过 **大小 + SHA-256 + minisign 签名** 三重校验；任一失败即拒绝安装。
- 镜像只换传输通道，校验不因换源而降级；签名/哈希失败同样换源。
- `latest.json` 的 `platforms.*.signature` 直接取对应 `.sig` 内容。

## 已知限制

- 未做 Authenticode / macOS 公证，系统仍会提示「未知发布者」。
- GitHub API 未认证时限流 60 次/小时；镜像可能同样限流。
- 仅升版本，不提供降级/回滚按钮。
- macOS / Linux 更新链路未在真机跑过；Windows 安装 → 退出 → 重启链路见下个版本的真机记录。

## 安装与首次运行

未签名构建的系统提示与放行步骤见 README「未签名构建的安装与首次运行」；放行只是绕过提示，
不等于签名问题已解决。

## 附件

- Windows：`Transmutio_*_x64-setup.exe` / `.msi`，GPL 变体对应 `Transmutio.GPL_*`
- macOS：`Transmutio_*_<arch>.dmg`
- Linux：`Transmutio_*_amd64.deb` / `.AppImage`
- 每个安装包对应的 `.sig`
- `latest.json`（LGPL）/ `latest-gpl.json`（GPL）
- `SHA256SUMS`：安装包与 `.sig` 的 SHA-256
