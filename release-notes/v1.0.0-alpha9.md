# Transmutio 1.0.0-alpha9

**alpha 版本，不建议日常使用。** 构建未做 Authenticode / macOS 公证；首次运行会触发系统提示。

## 本阶段修复

- **安装后自动重启（缺陷修复）**：Windows NSIS 安装器此前只收到 `/S`，安装完成即退出、不会拉起新版本。
  现改为 `/S /R`：`/S` 完全静默，`/R` 让安装器在成功后以当前用户身份重启应用
  （Tauri 的 `installer.nsi` 只在静默 / 被动模式下解析 `/R`）。
  MSI 路径改用 `msiexec /qn /norestart`，并在界面文案如实写「安装完成后请手动打开」，不再宣称自动重启。
- **码率语义拆分为四种**：默认 / 恒定质量 / 目标码率 / 保持原始。
  - 默认：不传任何码控参数（x264 / x265 缺省 CRF 23），体积不保证与源相近；
  - 保持原始：探测源视频 / 音频码率并用它作为目标（视频 `-b:v`、音频 `-b:a`），体积接近源；
  - 兼容旧数据：内部枚举别名 `same` / `original` / `copy` / `keep` / 「与源相同」一律映射到「保持原始」。
- **「恒定质量」档位化**：五档（近乎无损 / 高质量（推荐）/ 标准 / 省空间 / 极小体积），
  界面默认只显示档位名与一句说明；CRF 数字收进「高级」展开区，可手填微调。
  内部仍以 CRF 数值保存与传递，预设按区间反解档位。
- **音频码率档位化**：标准 / 高 / 更高 / 极高 + 默认 + 保持原始，具体 kbps 收进「高级」；
  换轨工具保留「默认 / 固定档位」（换轨场景没有「保持原始」）。
- **分辨率 / 帧率标签口语化**：4K / 2K / 全高清 / 高清 / 标清，标准 / 流畅，数值作为标准名保留。

## 平台能力

| 平台 | 能力 |
| --- | --- |
| Windows（NSIS `-setup.exe`） | 检查 + 安装（安装器静默运行，应用退出后完成安装并自动重启） |
| Windows（MSI） | 检查 + 安装（静默安装，不自动重启，安装完成后请手动打开） |
| macOS（`.dmg`） | 检查 + 下载（打开 DMG 手动拖入「应用程序」） |
| Linux AppImage | 检查 + 安装（替换当前 AppImage 后重启） |
| Linux deb | 检查 + 下载（安装交给包管理器） |

## 已知限制

- 未做 Authenticode / macOS 公证，系统仍会提示「未知发布者」。
- GitHub API 未认证时限流 60 次/小时；镜像可能同样限流。
- 仅升版本，不提供降级/回滚按钮。
- 保持原始无法逐字节复现源码率：实测输出与源偏差在 ±5% 内，见交付报告。

## 附件

- 三平台安装包（LGPL / GPL 两个变体）+ 每个包对应的 `.sig`
- `latest.json`（LGPL）/ `latest-gpl.json`（GPL）
- `SHA256SUMS`：安装包与 `.sig` 的 SHA-256
