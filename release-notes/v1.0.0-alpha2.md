## Transmutio 1.0.0-alpha2

**这是 alpha 预发布，不建议日常使用。** 后续每个完成块递增 alpha 序号，全部完工才发正式 `1.0.0`。

### 本阶段做了什么：CI 三平台出包（唯一发布路径）

- `release.yml` 接回并改写：**tag `v*` 触发**，`windows-latest` / `macos-latest` / `ubuntu-22.04` 三平台各自构建 LGPL 与 GPL 两个变体。
- **附件由 CI 生成**：Windows（MSI + NSIS）、macOS（DMG）、Linux（`.deb` / `.AppImage`），并自动汇总 `SHA256SUMS`（文件名按 GitHub 资产名归一，空格替换为点）。
  Linux 暂无 `.rpm`：RPM 的版本号字符集不接受 semver 的 `-alpha2`，而 Tauri 又要求配置版本是合法 semver，两者冲突，本阶段先跳过 rpm。
- **单一发布路径**：不再手工上传同名附件；手工 Release 与工作流并存会产生的「两个 Release / 附件被覆盖」问题收敛为 CI 一处。
- **版本闸门**：发布前先跑版本规则自测与 `check-version --tag`，构建后再用产物 `--version` 复核；tag、版本文件、二进制三者不一致会直接失败。
- Release 正文改为读取仓库内 `release-notes/<tag>.md`，说明与代码同源、可审计。

### 许可（两层，互不替代）

- **应用代码：MIT**（根 `LICENSE`）。
- **安装包不包含 FFmpeg / Poppler 二进制**：FFmpeg 在首次启动引导页选择本机文件并校验版本 / 构建配置 / SHA-256 后落位；「PDF 转图片」需自备 Poppler 的 `pdftoppm`。本项目未修改 FFmpeg / Poppler 源码（<https://ffmpeg.org/download.html>、<https://gitlab.freedesktop.org/poppler/poppler>）。
- LGPL 版只接受 LGPL 构建；GPL 版只接受 GPL 构建（含 libx264/libx265）。这只是所接受的 FFmpeg 构建路线，不是应用代码双许可。

### 已知限制

- **安装包未签名**：Windows SmartScreen 提示「未知发布者」；macOS 首次打开会被 Gatekeeper 拦截，需在「系统设置 → 隐私与安全性」手动放行；Linux 无签名校验。未购买签名/公证，这是如实说明，不是已解决问题。
- macOS 构建为 `macos-latest`（Apple Silicon）；Intel Mac 产物本轮未单独构建。
- macOS / Linux 目前只验证到「CI 能构建出安装包」，窗口启动与一次转码的最小实跑在下一阶段验证。
- 仍未实现：Office 互转 / 文档转 PDF、光盘 / DVD / ISO、工具集、EXIF 元数据写入、AVIF 编码、更新器实装。
- 其他：PNG 目标大小压不到、烧录字幕与变速互斥、图片压缩不支持逐轮取消、GIF 仅等间隔帧。
