# Transmutio 1.1.1

补丁版（`1.1.1`）。只修复 `1.1.0` 发布后发现的四处误导性界面问题，不新增功能。
安装包仍未做 Authenticode / macOS 公证；更新包仍带 minisign 签名。

## `1.1.0` 的具体缺陷

1. **PDF 工具目录指向不存在的控件**：缺少 `pdftoppm` / `pdftotext` 时，面板提示去设置页填写
   「PDF 工具目录」，但 `1.1.0` 的设置页没有这个输入框，`pdfToolsDir` 只由「自动下载 Poppler」
   写入。用户实际只能用环境变量或自动下载。
2. **引导页 GPL 提示指向隐藏按钮**：LGPL 发布版提示「开启下方开关」，但
   `devOverrideAvailable=false` 时「仅本机开发：允许 GPL」按钮并不渲染。
3. **设置页 GPL 开关无效**：LGPL 发布版显示「允许 GPL / nonfree 编码器」开关，但编译期固定
   拒绝，拨动没有任何效果。
4. **首页副标题过期**：副标题写「本版实现：视频转码 · 音频转码 · 图片批量转换/缩放」，
   与现有的序列、PDF 能力不符。

## 本版改动

- 设置页新增「PDF 工具目录（Poppler）」输入框：支持 `<dir>\Library\bin` 与 `<dir>\bin`，
  修改后立即重新检测；自动下载 Poppler 仍会写入该设置。
- 引导页 GPL 提示按 `devOverrideAvailable` 条件渲染：发布版只提示改用 GPL 版，
  debug 构建才提示可点击「仅本机开发：允许 GPL」按钮。
- LGPL 发布版设置页不再显示无效的 GPL 开关，改为静态「发布版固定拒绝」说明；
  debug 构建保留开关。
- 首页副标题改为「视频 · 音频 · 图片 · 序列 · PDF（合并 / 拆分 / 转图片 / 转文本）」。
- `jobs.rs` 中 PDF 工具目录注释补上 `pdftotext`（仅注释，无行为变化）。

## 已知限制（不美化）

- **安装包未签名**：无 Authenticode、无 Apple Developer ID / 公证，Windows SmartScreen 与
  macOS Gatekeeper 会提示未知发布者；更新包的 `.sig` 是 minisign，与应用签名不是一回事。
- **PDF 工具目录输入框未做真实窗口点击验证**：只验证了 headless 渲染、设置写入与重新检测；
  可见窗口内的点击与保存仍需真机确认。
- macOS / Linux 由 CI 构建，本版没有实机运行验证；Windows 为真机验证平台。
- `1.1.0` 的其他已知限制不变：PDF→TXT 依赖外部 `pdftotext`、混音无逐轨推子、
  PDF→DOC/XLS/HTM 未做、FFmpeg / Poppler 不随包分发、仅升版本不提供降级/回滚。

## 附件

- Windows / macOS / Linux 安装包（LGPL / GPL 两个变体）+ 每个包对应的 `.sig`
- `latest.json`（LGPL）/ `latest-gpl.json`（GPL）
- `SHA256SUMS`：安装包与 `.sig` 的 SHA-256
