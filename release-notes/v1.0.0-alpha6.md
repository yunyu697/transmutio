# Transmutio 1.0.0-alpha6

**alpha 版本，不建议日常使用。** 构建未做 Authenticode / macOS 公证；首次运行会触发系统提示。

## 本阶段做了什么

- **更新器实装**（设置页 › 诊断与更新），交互与 Renomio 对齐：
  - 只放一个「检查更新」入口；未检查时只显示「检查更新」与「打开主页」；
  - 检查中按钮禁用并显示「检查中…」；
  - 只有确实发现新版本才出现「更新」「仅下载」，并显示版本号、包大小、来源；已是最新显示
    「当前已是最新版本（…）」；
  - 「更新」= 下载 → 校验 → 启动安装 → 应用退出（Windows 安装器完成后重启）；
  - 「仅下载」= 落默认下载目录，按钮变「安装」，安装前再做大小 + SHA-256 + 签名二次校验；
  - 已下载且校验通过的包持久化，即使随后检查为「已是最新」也保留「安装」。
- **多镜像回退**：GitHub 官方 + gh-proxy / ghfast / ghproxy.net / mirror.ghproxy；
  按「用户所选镜像 → 官方 → 其余镜像」逐个尝试，失败原因逐条展示；哈希/签名失败同样换源，
  **不降级跳过校验**。
- **下载可靠性**：临时文件 + `Range` 断点续传；失败/换源立即清理；启动清理 `.part` 残留与
  过期 pending。
- **签名方案**：沿用 minisign（更新包）+ Authenticode（系统信任）双密钥设计；本次未生成密钥。
  `src-tauri/updater.pub` 为空时安装 **fail-closed**，不会假装已校验。
- 平台能力如实标注：Windows「检查 + 安装」；macOS「检查 + 下载（打开 DMG）」；
  Linux AppImage「检查 + 安装（替换后重启）」；Linux deb「检查 + 下载」。
- 发布流水线可选签名步骤：配置 `TAURI_SIGNING_PRIVATE_KEY` 后自动生成 `.sig` 附件。
