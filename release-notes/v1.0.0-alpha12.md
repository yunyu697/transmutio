# Transmutio 1.0.0-alpha12

**alpha 版本，不建议日常使用。** 构建未做 Authenticode / macOS 公证；首次运行会触发系统提示。

## 本阶段修复

- **移除旧版（FormatForge）数据迁移**：删除 `src-tauri/src/migration.rs` 与
  `migration_notice` / `legacy_import_info` / `import_legacy_data` 三个命令、
  启动前迁移调用、设置页「从旧版导入数据」入口与顶部迁移提示。
  新版只使用自己的数据目录和 `transmutio:*` 键；磁盘上残留的 `formatforge:*` 键
  不读取、不迁移、不删除，留着无影响。旧版并存拦截保持不变。
- **视频面板的音轨旧值兼容补齐**：历史上保存过 `audioRateMode=default` 的视频参数，
  读回时界面会显示旧的 320 kbps，而后端实际按 128 kbps 编码（不一致）。
  现统一归一化为「固定档位 + 128 kbps」，界面与实际输出一致。
- 其余 alpha11 改动保持不变：删除「默认」、保持原始的空档行为写死为视频 4000 kbps /
  音频 128 kbps、旧 `default` 映射到「标准」CRF 23 与 128 kbps、分辨率/帧率/图片质量保持裸数字。
- 安装流程与版本探测不变：Windows NSIS 静默安装仍为 `/S /R`，安装完成后自动重启；
  `--version` 自 alpha10 起可用。

## 平台能力

| 平台 | 能力 |
| --- | --- |
| Windows（NSIS `-setup.exe`） | 检查 + 安装（安装器静默运行，应用退出后完成安装并自动重启） |
| Windows（MSI） | 检查 + 安装（静默安装，不自动重启，安装完成后请手动打开） |
| macOS（`.dmg`） | 检查 + 下载（打开 DMG 手动拖入「应用程序」） |
| Linux AppImage | 检查 + 安装（替换当前 AppImage 后重启） |
| Linux deb | 检查 + 下载（安装交给包管理器） |

## 已知限制

- 未做 Authenticode / macOS 公证，系统仍会提示「未知发布者」。
- GitHub API 未认证时限流 60 次/小时；镜像可能同样限流。
- 仅升版本，不提供降级/回滚按钮。
- 保持原始无法逐字节复现源码率，实测输出与源存在小幅偏差（以交付报告为准）。

## 附件

- 三平台安装包（LGPL / GPL 两个变体）+ 每个包对应的 `.sig`
- `latest.json`（LGPL）/ `latest-gpl.json`（GPL）
- `SHA256SUMS`：安装包与 `.sig` 的 SHA-256
