# Transmutio 1.1.0

功能版本。相对 `1.0.0` 新增视频任意矩形裁剪、设备预设模板、PDF→TXT、音频混音，并补齐 PDF→TXT 的依赖缺失提示。构建未做 Authenticode / macOS 公证；首次运行仍会触发系统提示。

## 新增功能

- **视频任意矩形裁剪（预览帧 + 框选）**：视频转码/裁剪面板新增「裁剪方式」切换。
  「自定义矩形」先用 ffmpeg 取一帧真实预览（PNG data URL，最长边按调用方限制），
  在预览图上拖拽框选，四个百分比输入框与选框双向同步；坐标越界、宽高为 0
  在入队前即拒绝。输出宽高按源像素换算并取偶数，x/y 用 `min(...)` 夹在画面内。
  实测：1280×720 取 x10%/y20%/50%×50% → 640×360，与独立参考
  `crop=640:360:128:144` 首帧 PSNR 58.51 dB；预览帧 PNG 480×270（33,573 字节）。
- **设备预设模板**：新增 iPhone / iPad（1080p H.264）、Android（720p H.264）、
  PSP（480p H.264）、BlackBerry（480p H.264）四套模板。只覆盖容器、编码、
  分辨率、帧率与音轨码率，裁剪/水印/变速等其它设置保持不变。
  实测：720p 源套用 Apple 模板 → 1920×1080 / 30.00 fps / libx264。
- **PDF → TXT**：新增「PDF 转文本」任务，调用外部 `pdftotext`
  （`-enc UTF-8`，可选保留版面）。入口与入队前都会检测工具：
  缺失时面板直接给出配置方式（设置页 PDF 工具目录 / `PDFTOTEXT_PATH` /
  自动下载 Poppler）并禁用开始按钮，不会等到任务跑起来才报错。
  实测：2 页真实 PDF → `pdf文本.txt` 52 字节，两页文字均命中。
- **音频混音**：新增「音频混音」任务与面板。逐路统一采样率/声道后
  `amix=inputs=N:duration=longest:normalize=1`，可选 EBU R128 响度归一化。
  实测：两路混音输出 3.000s（取最长一路）、44.1 kHz / 立体声、
  最大音量 −21.5 dB（未静音且未削波）。

## 升级说明

- 升级后会自动清理旧版遗留的两个存储键：`transmutio:storage-migration:v1`
  与 `transmutio:migration-notice-dismissed`。清理只在首次启动执行一次，
  由独立标记位 `transmutio:cleanup:v2` 控制；失败不影响启动，也不触碰
  `transmutio:settings` 与各面板参数。

## 本版不做

- 音频混音的逐轨音量推子与试听波形（当前为等权混合，时长取最长一路）
- PDF→DOC / XLS / HTM（PDF→TXT 已实现）
- Delogo（去水印区域）、外挂字幕加载 / 多轨切换
- 光盘 / DVD / BD / CD 抓取、ISO/CSO、刻录
- Office 互转、PDF 加密压缩
- 批量重命名、媒体信息查看器、屏幕录制、站点视频下载

## 已知限制（不美化）

- **PDF→TXT 依赖外部工具**：`pdftotext` 未随安装包分发，Windows 也不是标配；缺失时任务在入队前即被拒绝，需按面板指引补装 Poppler 或配置路径。
- **安装包未做 Authenticode / macOS 公证**：Windows SmartScreen 与 macOS Gatekeeper 会提示未知发布者；更新器 `.sig` 为 minisign 体系，与代码签名不是一回事。
- FFmpeg / Poppler **不随安装包分发**，由用户自行准备并在首次启动时校验落位。
- 音频混音为等权混合，无逐轨音量推子；不做交叉淡化。
- 设备预设不做 profile/level 深度适配，码控仍沿用面板当前设置。
- 任意矩形裁剪的预览帧依赖 ffmpeg 抽帧，无关键帧时间轴拖动预览。
- 保持原始码率无法逐字节复现源码率，实测输出与源存在小幅偏差。
- GitHub API 未认证时限流 60 次/小时；镜像可能同样限流。
- 仅升版本，不提供降级/回滚按钮。
