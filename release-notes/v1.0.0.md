# Transmutio 1.0.0

首个正式版（`1.0.0`，无 alpha 后缀）。相对 `1.0.0-alpha12`，本版修掉了发布前自查发现的假功能与发布闸门，并补齐音频合并/截取。构建未做 Authenticode / macOS 公证；首次运行仍会触发系统提示。

## 相对 alpha12 的改动

### 假功能与发布闸门（六项）

- **F1 文字水印**：从“只有图片水印”改为真实 `drawtext`。支持中文文本、系统字体（`.ttf/.otf/.ttc`）、字号百分比、文字颜色、描边宽度与颜色、九宫格/自定义位置；字体路径转义已按真实 ffmpeg 验证。文本通过 `textfile=` 传入并逐字节保留，单引号、反斜杠、冒号、逗号、分号、方括号都不会被吞掉或破坏滤镜。缺字体在入队时即报错（“字体文件不存在”），不会静默失败。
- **F3 序列「起始编号」**：移除手动输入。`-start_number` 必须与文件名实际编号一致，任意输入会读错帧；现在一律按文件名自动推导，并补了断言（`frame_0005..0008` → `-start_number 5`）。
- **F4 界面语言 en-US**：移除语言下拉。本版仅提供简体中文；`en-US` 词典仍是未完成骨架，界面明确标注“暂不提供切换”，不再保留点了没反应的选项。
- **F5 预设 `afterAction`**：导入预设时会正确应用“批次完成后的动作”（不动作 / 打开目录 / 关机），并提示“批次完成后的动作已同步”。
- **命名模板校验 FAIL**：根因是本地/并发运行残留的旧输出文件（`模板-1.mp4`）触发冲突后缀，不是逻辑缺陷。用例前置清理后回归全绿。
- **LGPL 合规证据**：重建 alpha12 LGPL 安装包并刷新证据，`check:bundle` 40/40；本版发布包沿用同一流水线重新生成。

### 音频合并 / 截取

- **音频合并**：多文件按添加顺序拼接，自动统一采样率与声道（逐路 `aresample/aformat` 后 `concat`）。实测 44.1k/stereo 2s + 48k/mono 3s → MP3 44.1k/stereo，时长 5.000s。
- **音频截取**：按时间区间截取（`-ss` 前置、`-t` 后置），支持批量同区间；实测 3s 文件取 `[0.5,2.5)` → 2.000s。
- 音频混音本轮不做，见下方“本版不做”。

### 自查发现项关闭情况

- 已关闭：F1（文字水印）、F3（起始编号）、F4（语言开关）、F5（预设 `afterAction`）。
- 仍保留为低优先级（文案或字段级不一致，不影响主流程）：F6（PDF 合并模式文案）、F7（更新器 `arch` 字段未用）、F8（音频变速卡片与面板反向不一致）、F9（字幕烧录质量档位未暴露）、F10（更新器下载来源日志措辞）。

## 平台能力

| 平台 | 能力 |
| --- | --- |
| Windows（NSIS `-setup.exe`） | 检查 + 安装（安装器静默运行，应用退出后完成安装并自动重启） |
| Windows（MSI） | 检查 + 安装（静默安装，不自动重启，安装完成后请手动打开） |
| macOS（`.dmg`） | 检查 + 下载（打开 DMG 手动拖入「应用程序」） |
| Linux AppImage | 检查 + 安装（替换当前 AppImage 后重启） |
| Linux deb | 检查 + 下载（安装交给包管理器） |

macOS / Linux 由 CI 构建，但本版没有实机运行验证；Windows 为真机验证平台。

## 本版不做

- 音频混音（多轨混合）
- 视频任意矩形裁剪 / Delogo
- 外挂字幕加载 / 多轨切换
- 光盘 / DVD / BD / CD 抓取、ISO/CSO、刻录
- Office 互转、PDF→Office/文本/HTML、PDF 加密压缩
- 设备预设模板、批量重命名、媒体信息查看器、屏幕录制、站点视频下载

## 已知限制（不美化）

- **安装包未签名**：无 Authenticode、无 Apple Developer ID / 公证，Windows SmartScreen 与 macOS Gatekeeper 会提示未知发布者。
- FFmpeg / Poppler **不随安装包分发**，由用户自行准备并在首次启动时校验落位。
- 保持原始码率无法逐字节复现源码率，实测输出与源存在小幅偏差。
- 音频合并不做交叉淡化；音频截取只支持同区间批量，无波形选点。
- 文字水印不支持多行文本（换行会被拒绝），无 emoji 专用字体回退，无水印预览。
- 更新器运行时探针依赖本机真实安装旧版 FormatForge，未安装时相关检查会显示 `hit=0`。
- GitHub API 未认证时限流 60 次/小时；镜像可能同样限流。
- 仅升版本，不提供降级/回滚按钮。
