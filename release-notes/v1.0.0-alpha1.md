## Transmutio 1.0.0-alpha1

**这是 alpha 预发布，不建议日常使用。** 版本规则：此后每完成一块递增 `alpha2`、`alpha3`…，全部完工才发正式 `1.0.0`。`v0.1.0` 保留为历史版本，不回改。

### 本阶段做了什么：许可证与版本规则

- **应用代码改为 MIT**：仓库根目录新增 `LICENSE`，覆盖整个仓库（含所有子目录）；README 与 `LICENSING.md` 用两层表把「应用代码 MIT」与「FFmpeg / Poppler 各自的 LGPL / GPL 路线」分开说明；第三方许可证文件保持原样。
- **版本单一来源**：只改 `package.json` 的 `version`，构建前注入 `tauri.conf.json`（含 GPL overlay）、`Cargo.toml`、`package-lock.json`；产物 `--version` 与关于页和 tag 一致。
- **版本校验接进 CI**：段位 ≤10、alpha 序号正数且单调递增、tag = `v<version>`、产物 `--version` 一致；反例 `0.11.0` / `alpha0` / `alpha01` / tag 不一致 / 产物不一致都会被拦。
- MSI：WiX 只接受数字型预发布标识，alpha 的 MSI 内部版本为 `1.0.0.<序号>`（文件名与显示仍是 `1.0.0-alpha1`）；从 alpha 升级到正式版建议先卸载。

### 附件与校验

- Windows x64：LGPL / GPL 各含 MSI + NSIS setup（本 alpha 为手工发布产物）
- `SHA256SUMS`：文件名按 GitHub 资产名（空格已替换为点），可用 `sha256sum -c` 或 `Get-FileHash` 比对。

### 许可（两层，互不替代）

- **应用代码：MIT**（根 `LICENSE`）。
- **安装包不包含 FFmpeg / Poppler 二进制**：FFmpeg 在首次启动引导页选择本机文件并校验版本 / 构建配置 / SHA-256 后落位；「PDF 转图片」需自备 Poppler 的 `pdftoppm`。本项目未修改 FFmpeg / Poppler 源码（<https://ffmpeg.org/download.html>、<https://gitlab.freedesktop.org/poppler/poppler>）。
- LGPL 版只接受 LGPL 构建；GPL 版只接受 GPL 构建（含 libx264/libx265）。这只是所接受的 FFmpeg 构建路线，不是应用代码双许可。

### 已知限制

- **安装包未签名**：Windows SmartScreen 会提示「未知发布者」；macOS 需手动放行 Gatekeeper。这是已知状态，不是本轮能解决的问题。
- 本轮只产出 Windows x64 包；macOS / Linux 构建与最小实跑尚未进行。
- 仍未实现：Office 互转 / 文档转 PDF、光盘 / DVD / ISO、工具集、EXIF 元数据写入、AVIF 编码、更新器实装。
- 其他：PNG 目标大小压不到、烧录字幕与变速互斥、图片压缩不支持逐轮取消、GIF 仅等间隔帧。
