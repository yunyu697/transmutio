# Transmutio 1.2.0

破坏性版本（`1.2.0`）。本版整体下线 PDF 功能并重构主界面，同时新增按方法记忆的命名预设。
安装包仍未做 Authenticode / macOS 公证；更新包仍带 minisign 签名。

## 不兼容变更（升级前必读）

1. **PDF 功能整体下线**：PDF 合并、PDF 拆分、PDF 转图片、PDF 转文本四项已从界面、命令、
   依赖与下载清单中全部删除。升级后不再有「文档」分区，也不再检测或调用
   `pdftoppm` / `pdftotext`，`PDFTOPPM_PATH` / `PDFTOTEXT_PATH` / `TRANSMUTIO_PDF_TOOLS`
   不再生效。已完成的输出文件不受影响，但升级后无法再用本应用发起新的 PDF 任务。
2. **已下载的 Poppler 目录不会自动删除**：旧版通过「自动下载 Poppler」落位到
   `<应用数据目录>/tools/poppler-*` 的文件会原样保留，不会被清理；确认不再需要后可自行删除。
3. **旧设置里的 `pdfToolsDir` 会被忽略**：该字段已从设置类型中移除，读取设置时既不迁移也不报错，
   只是不再产生任何效果；其余设置与面板参数保持原样。

## 界面重构

- 删除顶栏，应用图标移入左侧栏顶部：使用应用自身的真实 PNG 图标，以 CSS 取景裁切呈现
  （24px 盒、34.03px 渲染、−5.02px 偏移、圆角 6px），并加一层极淡内描边，
  避免深色主题下底板与背景同色导致轮廓消失。
- 左栏支持 236px ↔ 64px 折叠，折叠状态持久化；折叠态为纯图标 rail。
- 首页固定三段：快速开始 3 卡 → 分区速览 3 卡（分区名、方法 chips、常用格式、适用场景、
  上次参数摘要、继续入口）→ 底部格式 / 输出策略 / 并发长条。
- 最近使用最多 4 条，按方法去重并置顶。
- 状态栏收敛为 5 组：FFmpeg、许可变体（构建信息并入同一组）、软编 / 硬编、并发 / 运行 / 排队、
  版本 + 平台。
- 移除「工具集」「文档」「光盘」分区与对应占位入口，界面上不再有指向未实现能力的控件。

## 新增：保存为预设

- 面板底部操作条新增次级按钮「保存为预设」，支持命名保存、列表、重命名、删除。
- 存储键 `transmutio:presets:v1`，按**方法**粒度记录上次使用的预设；快照只保留
  字符串 / 数字 / 布尔参数，不含绝对路径与凭据字段。
- 再次进入同一方法时自动载入上次预设，并给出可撤销提示。
- 预导入 / 导出（`transmutio:*` 命名空间）行为不变。

## 移除与清理

- 后端删除 4 条 PDF 命令、`pdf.rs`、`pdf_tools.rs`、`lopdf` 依赖与 `run_pdf` 实现。
- 引导页与 `tools-manifest.json` 删除 Poppler 下载项；macOS / Linux 的 Poppler 手动安装提示一并移除。
- 设置页删除「PDF 工具目录」区块；「默认输出目录」改为「输出位置」单选
  （与源文件相同目录 / 自定义目录）。
- `licenses/Poppler.txt` 保留并标注「历史声明，当前版本不再调用」。
- 测试与静态断言中的 PDF 用例、Poppler 下载断言全部删除；新增改版与预设的 DOM 断言。

### 真机验证

- 平台与安装包：Windows x64，`Transmutio GPL_1.2.0_x64-setup.exe`（本地构建，
  SHA-256 `c99dbbc751be0e983b4e505a3bb13901d35ea515f69c49fca409f95eb3eb3149`），
  静默安装到 `%LOCALAPPDATA%\Transmutio GPL`，注册表 `DisplayVersion = 1.2.0`。
- 操作与读回（真实安装包窗口，非 mock 浏览器）：
  1. 打开「视频转码」，把分辨率改为 `720`，保存预设「跨会话验收」；
     读回 `transmutio:presets:v1`：`presets=1`、`methodId=video-mp4`、`params.resolution=720`、
     `last["video-mp4"]` 指向该预设。
  2. 关闭主窗口（正常 `WM_CLOSE`，进程退出码 `0`），重新启动应用。
  3. 再次打开「视频转码」：分辨率下拉读回 `720`，提示条读回
     「已载入上次预设「跨会话验收」撤销」，预设存储仍在。
- 结论：跨会话自动带回上次预设与撤销提示均已生效。
  （测试方式说明：通过 WebView2 调试端口在真实窗口内触发点击与读取；
  若用强制结束进程代替正常关窗，WebView2 可能来不及落盘 localStorage，不作为验证路径。）


## 已知限制（不美化）

- **安装包未签名**：无 Authenticode、无 Apple Developer ID / 公证，Windows SmartScreen 与
  macOS Gatekeeper 会提示未知发布者；更新包的 `.sig` 是 minisign，与应用签名不是一回事。
- macOS / Linux 由 CI 构建，本版仍无实机运行验证；Windows 为真机验证平台。
- FFmpeg 不随包分发；预设只记录面板参数，不记录输入文件路径与输出目录。
- 仅升版本，不提供降级 / 回滚。
