# Transmutio 1.3.3

补丁版本（`1.3.3`），把文件列表从「只能加/删」补到接近资源管理器的交互水平。
列表顺序就是视频合并、音频拼接的处理顺序，因此本轮所有排序、拖动都是**物理重排**，
不做仅影响显示的视图排序。

## 选择与框选

- Ctrl 点击切换单项；Shift 点击按锚点选中范围（正反向都支持）；Ctrl+Shift 把范围
  **增量并入**当前选择。
- 空白处按下拖动为框选，拖动过程中实时高亮命中行；按住 Shift（或 Ctrl）框选为追加。
- `Ctrl+A` 全选、`Esc` 清除、`↑`/`↓` 移动焦点、`Shift+↑`/`↓` 扩展选择、`Home`/`End` 跳首尾。
- 状态栏显示「共 N 个 · 已选 M」；选中态（底色）与焦点态（左侧强调条）视觉分开。

## 排序

- 表头显示当前排序状态：`按名称 · 升序` / `按大小 · 降序` / `自定义顺序`。
- 右键菜单「排序方式」支持名称、类型、大小、时长，升序/降序切换。
- **排序会改变合并顺序**，菜单项旁有注解；每次排序后提示「合并顺序已更新」。
- `#` 序号列跟随可见顺序重排。
- 「恢复添加顺序」按文件最初加入列表的序号还原，不是撤销栈。

## 拖动排序

- 整行可拖，位移超过 4px 才启动，避免和点击、双击冲突。
- 拖动时有跟手拖影、目标位置插入指示线，落下后该行短暂高亮，列表上下边缘自动滚动。
- `Esc` 取消且顺序不变；拖动结束不会触发打开或双击。
- 多选拖动时，选中行按当前顺序整理成一个连续块整体插入落点，不会各自散开。

## 重命名（真实改动磁盘）

- `F2` 就地重命名，`Enter` 提交、`Esc` 取消。
- 新增 Rust 命令：只改同目录内的文件名，支持只改 stem（保留原扩展名）或写全名；
  目标已存在直接拦下并提示；失败时列表状态不变并显示错误。
- 改名成功后重新探测该文件（大小、时长、格式可能变化），并保留选中与焦点。
- 批量重命名支持模板（如 `{name}-{n}`、起始序号、0–6 位补零）；执行前做冲突预检，
  有冲突时禁用执行并逐条列出原因，不会半途失败。
- 实现为「可测纯逻辑 + 薄命令层」，`file_ops.rs` 内含 8 个单元测试。

## 右键菜单

- 空白处：粘贴、从剪贴板导入路径、全选、取消选择、排序方式（含注解与恢复添加顺序）、
  显示方式（详细/紧凑）、刷新。
- 选中项：打开、在文件管理器中显示、重命名、复制、剪切、复制路径、从列表移除、属性；
  多选时替换为批量重命名…、移除选中的 N 项。
- 右键点在已选中项上保留现有多选；点在未选中项上才改为单选。
- 菜单支持方向键、Enter、Esc、首字母跳转，点击外部关闭，贴边自动翻转。

## 队列剪贴板

- 复制 = 记住路径并写入系统剪贴板；剪切 = 标记为待移动并标灰；粘贴 = 插入落点
  （无落点则末尾），插入后清除剪切标记。
- 粘贴已存在的项提示「N 项已在列表中」并把已有行高亮，不产生重复行。
- 队列剪贴板为空时，`Ctrl+V` 回退为从系统剪贴板文本按行批量导入路径；菜单里另有
  「从剪贴板导入路径」入口，队列非空时也能强制走系统剪贴板。
- **不复制磁盘文件**。

## 从列表移除

- `Delete` 与菜单「从列表移除」只把文件移出队列，**不删除磁盘文件**，本轮不加回收站。
- 属性/详细信息里显示真实路径，需要删盘时用户可自行去资源管理器处理。

## 外部拖入路由修复

- 修复：一个面板挂多个列表时（音频面板 3 个、高级面板 5 个），一次系统拖放会把同一批
  文件同时加进多个列表。
- 现在窗口级只订阅一次系统拖放，再按松手坐标路由到命中的那个列表；未命中任何列表时
  落到该面板第一个列表并追加到末尾。落点插入语义不变：命中列表按坐标算插入位置。
- 空列表也参与命中（插入到 0 位），不再只能靠兜底追加。

## 焦点信息条

- 状态栏显示焦点项的文件名、真实路径、时长/尺寸、扩展名、大小与在列表中的序号
  （`#i/N`），键盘移动焦点时同步更新。

## 行为变化提示

- 排序是物理重排，会改变合并/拼接顺序；随时可用「恢复添加顺序」还原。
- `Delete` 的含义是「从列表移除」，与资源管理器不同，不会动磁盘。
- 空状态文案改为「文件不会被复制；仅「重命名」会改动磁盘上的文件名」。

## 验证

- `npm run build`：TypeScript 类型检查 + Vite 构建通过。
- `npm run test:list`：**24 项全 PASS**（17 项选择/排序/拖动纯逻辑 + 7 项多列表面板
  拖放路由）。
- `npm run test:rust`：**172 项全 PASS**（含 `file_ops.rs` 的改名/批量重命名 8 项）。
- `npm run version:test` 18 项、`verify:theme` 72 PASS/0 FAIL、`verify:formats` 30/30、
  `check:bundle` 36/36、`check:ffmpeg-license` 通过。
- `verify:legacy-guard`：4/6，2 项 `nsisProbe` 因本机没有旧版 FormatForge 注册表项而
  失败，属于环境前置条件不满足，与本版本改动无关。

**未做真实窗口人工走查**：本轮按约束没有启动应用窗口，所以拖影手感、框选矩形、
菜单贴边翻转、多列表面板拖放归属、`F2` 在输入法下的行为等，仅通过类型检查、构建、
纯逻辑单测与 Rust 单测验证，需要在真机窗口里确认。

## 安装与校验

- 安装包**未签名**：无 Authenticode、无 Apple Developer ID / 公证；更新包 `.sig`
  是 minisign 签名，与代码签名不是一回事。
- FFmpeg 不随包分发，运行时按设置里的路径或自带构建解析；本版本未改动转码链路与
  预设格式。
- 每个 Release 附 `SHA256SUMS`（安装包与 `.sig` 的 SHA-256），下载后可自行核对。
